# Quick setup

1. Zainstaluj Flutter SDK (zalecana wersja: 3.7.2 lub wyższa).
2. Upewnij się, że masz zainstalowane narzędzia deweloperskie dla swojej platformy (Android Studio/Xcode (IOS)).
3. Zainstaluj zależności:
   ```
   flutter pub get
   ```
4. Uruchom aplikację na podłączonym urządzeniu lub emulatorze:
   ```
   flutter run
   ```

Wymagania:
- Flutter SDK >= 3.7.2
- Android/iOS emulator lub fizyczne urządzenie
